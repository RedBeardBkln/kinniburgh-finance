## Defects found (none blocking)

1. **Low - punctuation-only payee becomes a nameless series.** Repro: rows with payee `***` (monthly, same amount) -> suggestion with key `E1|A1|out|` and payee `""`; two distinct punctuation payees (`***`, `###`) on different days merge into one biweekly nameless series and a late flag whose text starts with a blank (` usually posts every two weeks...`). Expected: such rows should be dropped or kept apart. Actual as stated. Live data: 0 rows canonicalise to empty, so latent only. "Add" would be refused by the zod min(1) name check.
2. **Low - unpaired card-payment descriptors on checking are not skipped.** Repro: `capital one mobile pmt`, `barclaycard us payment` or `amex epayment ach pmt`, monthly fixed 100.00 from a checking account -> offered as a high-confidence recurring expense; adding it would double count card spending. (`credit card payment ...` is skipped via "card pay".) Live: checking has 11 unpaired `capital one crcardpmt` and 3 `amex epayment ...` rows, but their amounts/dates are irregular so none is suggested today.
3. **Low - typical amount lags a small price change.** Google One: last 6 payments 21.26, earlier 11 at 21.76, median over all 17 = 21.76, so "Add as recurring expense" would record 21.76 (about 2.4% high) and no amount-change flag fires (diff $0.50 is under the $2 / 10% gate, by design). Same source gives the odd text "Seen 17 times, 1-33 days apart" (a May 6/7 pair of charges counts as an interval of 1 day).
4. **Low - Add is a name-based find-then-create, not atomic.** Two near-simultaneous clicks can create two rows (no unique constraint on name). Also two same-named series on different accounts (live: "Maintenance Fee" on two accounts) cannot both be added: after the first, the second is suppressed by name and the action answers "Already recorded", although it is a separate $15 charge. The plan acknowledged RecurringExpense has no account.
5. **Informational - dashboard/forecast latency.** About +0.7 to +1.5 s per load from the detection reads (see cost). Coder flagged it; `Suspense` not pre-built.
6. **Informational - cosmetics/heuristics.** A trailing word equal to a US-state code is stripped (`friends in` -> `friends`, `jiffy mart co` -> `jiffy mart`); a "Weak pattern, 17 times" label for Netflix (day drifts), as the Coder noted. `forecast/page.tsx` computes `toUiDetection(...)` in the same try as the agenda, so a throw there (none found) would blank the agenda instead of only the add-on.
