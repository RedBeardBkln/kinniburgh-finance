## Defects / observations

No blocking defects. None of these fail an acceptance criterion.

1. **Inherited month-length gap is wider than documented (Medium for owner awareness, non-blocking).** `lib/forecast.ts#allMonthDays` skips a day that does not exist in a month, and the ledger inherits it for every monthly bill, Budget schedule and paycheck, not just the `[15, 31]` paycheck named in the code comment, CLAUDE.md and the Coder's notes. Live example: Toyota Financial is on day 30. Repro (real builder): `buildUpcomingLedger({from: 2027-02-10, days: 30, bills:[monthly bill, autopayDay 30]})` returns no item, no undated entry and no note (a window starting 2027-01-20 shows only Jan 30). So from about 2027-01-08 the 90-day view will silently omit the February Toyota payment ($420). Today's windows are unaffected (Nov 30 and Dec 30 are present). The plan forbids changing `forecast.ts` and marked this as to be flagged, so this is not a plan failure, but the stated scope (paychecks only) understates it and it contradicts the "no bill silently dropped" intent. Suggest the follow-up task for day-31 / clamp also covers bills, Budget schedules and the ledger's own wording, or that the ledger clamps for itself.
2. **Zero-amount inflow sources render as known $0.00 (Low).** A ProjectedRevenue with `amountCents: 0`, a RentalBooking with `grossEarnings: 0`, an IncomeSource with `amount: 0` and a ScheduledTransfer with `amount: 0` are emitted as `amountStatus: "known"`, amount 0.00 (probe output: `projected_revenue known 0.00`, etc.). Plan 5.2 only requires the unknown-amount rule for bills, cards and Budget lines, and the schema documents these as positive amounts, so this is an edge, but a row would show "+~$0.00" instead of "amount not set".
3. **Agenda week header shows "~$0.00 due" / "~$0.00 expected in" for weeks with none (Low, cosmetic).** Live example (Personal agenda, "Week of Oct 5": "~$0.00 due, ~$2,555.00 expected in"). It is a true zero total, not an unknown amount, and the dashboard strip already hides a zero "expected in" segment (Coder deviation 6); the agenda is inconsistent with that. A week containing only unknown-amount bills would also read "~$0.00 due" (the dashboard strip mitigates with the "N items have no amount set" line; the week header does not).
4. **Doc nit (Informational).** Coder's notes say lint produced 53 warnings; I measure 52 (all pre-existing, none in new files). No action.
